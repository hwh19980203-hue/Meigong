# Codex 出图指令模板

## 用途

这是一份给美工直接复制使用的模板。

目标不是讲原理，而是让同事在找 Codex 出图时，尽量一次把信息说对，减少模型乱猜、产品跑偏和多轮返工。

适用场景：

- 主图
- A+ 图
- 场景图
- 细节图
- 尺寸图
- 改图迭代

## 使用原则

每次发给 Codex 的指令，尽量都包含这 6 类信息：

1. 任务类型
2. 产品信息
3. 参考图角色
4. 图的目标
5. 不可变约束
6. 输出要求

## 主图模板

```text
帮我做这款产品的主图。

任务类型：
亚马逊主图

产品信息：
产品编号：
产品名：
店铺：
站点：

参考图：
Image 1 是白底图 / 已确认首图 / 实拍图，作为产品主体唯一参考。
Image 2 是细节参考图，用来确认材质、边缘、结构、拉链或印花。

目标：
做一张更适合电商点击的主图，产品清楚、排布稳、信息一眼能看懂。

不可变约束：
- 必须严格参考产品外形
- 数量必须准确
- 配色必须准确
- 不允许改产品结构
- 不允许新增不存在的配件
- 不允许让产品看起来像另一款产品

希望优化的地方：
- 排布更整齐
- 产品更饱满 / 更立体
- 白底更干净
- 更适合亚马逊缩略图点击

输出要求：
先复述你理解的主图重点，再开始生成。
```

## A+ 图模板

```text
帮我做这款产品的 A+ 图。

任务类型：
A+ 图

产品信息：
产品编号：
产品名：
店铺：
站点：

参考图：
Image 1 是锁定产品母版，必须作为产品主体参考。
Image 2 是实拍细节参考。
Image 3 是氛围 / 构图参考，只参考版式和气氛，不参考产品外形。

目标：
这张 A+ 图主要表达：
[英雄图 / 套装内容 / 材质细节 / 使用步骤 / 多场景 / 尺寸容量]

不可变约束：
- 必须沿用同一产品主体
- 不允许整图重绘产品
- 不允许改产品形状、比例、数量、颜色、结构
- 不允许增加包装内不存在的内容

希望优化的地方：
- 场景更有氛围
- 版式更高级
- 信息层级更清晰
- 更适合美国站 A+ 视觉

输出要求：
先告诉我这张图你会怎么布局，再开始生成。
```

## 场景图模板

```text
帮我做这款产品的场景图。

任务类型：
场景图

产品信息：
产品编号：
产品名：
店铺：
站点：

参考图：
Image 1 是产品主体参考。
Image 2 是产品细节参考。
Image 3 是场景氛围参考。

目标：
让用户一眼理解这个产品适合在什么场景使用。

场景方向：
[家庭 / 户外 / 节日 / 派对 / 礼品 / 美式日常 / 收纳 / 旅行]

不可变约束：
- 产品必须和参考图保持一致
- 场景只是辅助，不是重画产品
- 不允许出现与产品无关且会误导买家的东西

希望优化的地方：
- 氛围更自然
- 背景更高级
- 产品主体更突出
- 更有生活方式感

输出要求：
先告诉我你打算怎么放产品、怎么放背景、怎么控制氛围。
```

## 细节图 / 信息图模板

```text
帮我做这款产品的细节图 / 信息图。

任务类型：
[细节图 / 信息图 / 尺寸图]

产品信息：
产品编号：
产品名：
店铺：
站点：

参考图：
Image 1 是产品主体参考。
Image 2 是细节局部参考。

目标：
重点讲清楚这些信息：
[尺寸 / 材质 / 结构 / 数量 / 使用步骤 / 细节卖点]

不可变约束：
- 产品细节必须真实
- 尺寸和数量不能写错
- 不允许为了好看改产品结构
- 文案要短、清楚、可读

希望优化的地方：
- 信息更清楚
- 排版更整洁
- 标签更少但更准

输出要求：
先告诉我这张信息图会分成几块，每块讲什么。
```

## 按模型区分的简写模板

### 更适合 GPT 的指令补充

适用于：

- 主图
- 信息图
- 尺寸图
- 强约束任务

可以额外加这段：

```text
这轮优先保证产品准确性，不要优先追求氛围感。
请严格参考产品图，先确保外形、数量、结构、颜色正确，再考虑画面优化。
```

### 更适合 Banana 的指令补充

适用于：

- A+ 氛围图
- 场景图
- 礼品感和桌面氛围探索

可以额外加这段：

```text
这轮重点是优化氛围、版式和场景感，但产品主体仍然必须参考锁定母版或实拍图，不能重画成另一款产品。
```

## 同事最容易漏写的东西

每次发指令前，快速检查：

- 有没有说清楚这是什么图
- 有没有说哪张图是主体参考
- 有没有写不可变约束
- 有没有写这轮到底要改什么
- 有没有写不要什么

## 最短版模板

适合很赶时间时直接发：

```text
帮我做一张 [主图 / A+ / 场景图 / 信息图]。

产品：
[产品编号 + 产品名]

参考图：
Image 1 是主体参考，必须严格保持产品一致。
Image 2 是细节参考。
Image 3 是构图 / 氛围参考。

目标：
[这张图要表达什么]

不能变：
[外形 / 数量 / 颜色 / 结构 / 配件]

想优化：
[构图 / 氛围 / 版式 / 饱满度 / 高级感]

先复述你的理解，再开始。
```
