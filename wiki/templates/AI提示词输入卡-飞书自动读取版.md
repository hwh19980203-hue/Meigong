# AI 提示词输入卡（飞书自动读取版）
## 真实启动顺序

这张卡不是第一步，真实顺序是：

1. 先报产品编号
   例如：`做 786`
2. Codex / Claude 先从飞书读取基础信息
3. 你再提供开发文档和实拍图
4. 然后再用这张卡整理美工视觉意图和本轮修改目标

换句话说，这张卡是“飞书数据 + 开发文档 + 实拍图”到位之后的整理层。

## 定位

这张卡不是给美工写提示词用的。

这张卡的作用是：

- 飞书多维表格自动提供产品基础事实
- 美工只补视觉意图和本轮修改目标
- Codex / Claude 根据两部分信息生成高质量提示词

一句话：

> 美工不写 prompt，只提供让 AI 写出好 prompt 的输入。

## 适用范围

适用于以下任务：

- 主图
- A+ 图
- 场景图
- 信息图
- 尺寸图
- 改图迭代

## 使用方式

1. 先从飞书多维表格按产品编号 / SKU / ASIN 读取基础信息
2. 自动带出历史案例、产品页、锁定母版和参考图
3. 美工只填写“人工补充区”
4. Codex / Claude 根据整张卡输出：
   - 作图 Brief
   - 模型建议（GPT / Banana）
   - Prompt 草案
   - 本轮修改 Prompt

## 怎么判断这张卡填得好不好

这张卡填得好，通常满足下面 5 条：

1. 不需要美工重复填写飞书已有字段
2. 说清了这是什么图
3. 说清了哪张图负责产品外形，哪张图只负责氛围
4. 说清了不能变什么
5. 说清了这轮只改什么

如果缺了这些，Codex / Claude 写出来的提示词稳定性会明显下降。

## 填写示例

```markdown
## 美工人工补充区

### 1. 任务类型
- [x] 主图

### 2. 本次任务目标
- 这张图主要卖什么：12 个化妆包套装，颜色多、可爱、适合礼品和收纳
- 这张图主要解决什么问题：让买家一眼看懂数量、配色和产品外形
- 这张图更偏：
  - [x] 产品准确
  - [x] 信息清楚

### 3. 参考图角色分配
- 主体参考图：786-main-image-v6-locked-master-1600.png
- 细节参考图：786-real-1~7.jpg
- 氛围参考图：无
- 构图参考图：当前主图排布参考

### 4. 不可变约束
- 产品外形不能变：包型、底部厚度、圆角、单拉链结构
- 数量不能错：12 个，6 色各 2 个
- 颜色不能错：必须保持现有 6 色
- 配件不能多也不能少：每个包只能有 1 条拉链和 1 个拉链头
- 文案事实不能错：不能写错数量和尺寸
- 不允许出现的元素：提手、肩带、包装盒、手、logo、多余配件

### 5. 本轮只改什么
- 保留不动：颜色顺序、整体排布、图案内容
- 当前出错点：包身不够鼓，底部支撑感不够
- 这轮只改的 1-3 个重点：
  1. 包更饱满
  2. 底部更有支撑感
  3. 保持其余地方不动
```

## 最重要的规则

不要把这张卡写成另一份 prompt。

这张卡只负责回答三件事：

1. 这次要做什么图
2. 这张图哪里不能错
3. 这轮到底改什么

剩下的事情，交给 Codex / Claude 写提示词。
