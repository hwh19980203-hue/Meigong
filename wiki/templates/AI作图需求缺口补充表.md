# AI 作图需求缺口补充表

> 本表用于”飞书多维表格已自动预填产品基础信息，但作图需求仍不完整”的情况。产品开发只补图片表达和合规相关缺口，美工再补视觉判断和执行策略。
>
> **⚠️ 核心原则：产品实拍图是所有 AI 出图的唯一产品外观依据。** 在填表、采集实拍图和后续出图的每个环节，实拍图优先级高于所有参考图、竞品图和 Word 文档中的样图。
> - 产品实拍图决定：颜色、材质、结构、形状、配件、数量、包装
> - 参考图/竞品图仅决定：构图、氛围、场景、风格
> - 两者冲突时，**以实拍图为准**

## 使用方式

1. Codex 先从飞书多维表格按 `编号` 或 `SKU` 读取产品记录
2. Codex 生成“自动预填字段”
3. 如果开发已提交 Word / 飞书文档 / Markdown 图片文档，Codex 先自动抽取参考图和每张图制作说明
4. Codex 同时读取产品实拍图文件夹，确认真实产品颜色、材质、结构、数量和包装
5. 如果图片任务信息仍不足，把本表发给产品开发补充
6. 开发补完后，美工填写“美工判断区”
7. Codex 再生成作图 Brief 和 GPT 提示词

## 3. 美工判断区

> 由美工填写，用于决定 AI 作图策略和精修重点。

```markdown
## 美工判断区

- 需求完整性：完整 / 需开发补充
- 实拍图是否足够还原产品：足够 / 需补拍
- Word 参考图与实拍产品是否存在冲突：无 / 有，需开发确认
- 实拍图是否已确认为实际销售产品实物：是 / 否 / 需开发确认
- 实拍图在出图过程中的优先级确认：实拍图为产品外观唯一依据 / 需补充说明避免AI混用参考图
- 是否适合 AI 出图：适合 / 部分适合 / 不适合
- 推荐出图方式：直接生成 / 垫图改图 / 局部重绘 / PS 合成优先
- 主要视觉方向：
- 可参考的历史案例：
- 可套用的模板：
- 主要合规风险：
- 主要 AI 幻觉风险：
- 预计返工点：
- Prompt 重点：
- 负面提示词：
```
