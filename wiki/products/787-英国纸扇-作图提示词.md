## 初筛检查清单

出图后逐张检查：

- [ ] 扇面颜色是否全白（无米黄、无金色色调）
- [ ] 手柄是否为白色塑料（非木色、非金属色）
- [ ] 固定卡扣是否可见且结构正确
- [ ] 首图背景是否纯白 RGB 255,255,255
- [ ] 首图是否无文字（仅 80pcs 标注除外）
- [ ] 产品占画面比例是否约 80%
- [ ] 尺寸图数字标注是否与产品事实一致
- [ ] 步骤图步骤是否清晰可读
- [ ] 英文文案是否拼写正确
- [ ] 是否存在未包含在产品内的多余配件

**A+ 专项**

- [ ] 英雄图和场景图尺寸是否为 970×600 px
- [ ] 三图模块每张是否为 300×300 px
- [ ] A+ 图 2 数量标注（80pcs）和尺寸数字是否准确
- [ ] 三图模块 3 张风格是否统一（背景、字体、色调一致）
- [ ] 所有 A+ 图扇面颜色是否全白（与主图一致）
