# 图片管理与 LLM 配合指南

> 本文档总结在 Obsidian 知识库中管理图片的最佳实践，特别是面向亚马逊美工部门的高图片密度场景，以及如何与 LLM 高效配合。

## 1. Obsidian 图片能力一览

| 能力 | 说明 |
|------|------|
| **原生嵌入** | `![[图片.png]]` 直接渲染显示，与图谱视图联动 |
| **附件管理** | 可指定统一附件目录（如 `raw/assets/`），所有图片自动归集 |
| **一键下载** | Obsidian Web Clipper 抓取网页后，Ctrl+Shift+D 将远程图片拉到本地 |
| **多图对比** | 结合 Image Layouts 等插件可并排对比多张图片 |

Obsidian 展示图片没有问题。真正的关键在于 **LLM 如何读取图片**。

---

## 2. LLM（Claude）读取图片的机制

Claude 是多模态模型，可以看懂图片内容（构图、配色、文字可读性、产品展示角度等）。**但在本知识库的工作方式中，图片读取不是自动的。**

### 2.1 核心机制：显式读图

当笔记里有 `![[raw/cases/786-马艳丽/786-real-1.jpg]]` 这样的嵌入时：

```
Claude 读取 .md 文件 → 看到的是文本 "![[path/to/image.jpg]]"
                         ↓
                 不会自动渲染图片
                         ↓
        需要用 Read 工具以图片文件路径读取 → 才能"看到"图片内容
```

**所以 Claude "看"到图片的流程是：**

```
Read 笔记.md          → 读到 ![[xxx.jpg]] 文本
                              ↓
Read raw/cases/xxx/xxx.jpg  → 多模态能力渲染，看到图片内容
```

### 2.2 工作流中的图片读取

在作图工作流中，Claude 必须按以下顺序读取图片：

1. **读文字优先** — 先读取笔记的 markdown 文本，了解上下文
2. **看到 `![[...]]` 时逐一读取图片文件** — 使用 Read 工具传入图片绝对路径
3. **理解图片后继续** — 图文结合后，再生成提示词或执行下一步

### 2.3 什么时候 Claude 会自动读图？

- **作图时**：AGENTS.md 要求必须读取实拍图作为参考 → Claude 会主动 Read 图片文件
- **分析/质检时**：用户要求看某张图 → Claude 会 Read 对应图片文件
- **日常查询时**：仅读取文本，不会自动追读图片（避免不必要的文件读取）

## 3. 给 LLM 看图的正确做法

### 3.1 笔记中保留 Alt Text

```markdown
![[raw/cases/786-马艳丽/786-real-1.jpg|实拍图1 — 产品整体展示，冰激凌水滴6色化妆包平铺]]
```

Alt Text（`|` 后面的文字）在 Claude 读笔记时提供第一手上下文，读图前即可知道图片内容。

### 3.2 直接要求 LLM 看图

在提问时明确指示：

> "帮我看看这张图 → 读取 raw/cases/786-马艳丽/786-real-1.jpg"
> "对比这两张图，哪张构图更好"

### 3.3 作图时的自动看图

AGENTS.md 的 "参考图强制传递" 规则已经规定：
- 作图前必须读取实拍图 → 自动调用 Read 读取图片文件
- 读取后在 prompt 中描述产品外观 → 传递给 API 作为参考

## 4. 图片目录结构

### 4.1 实际使用的路径约定

| 图片类型 | 存放路径 | 示例 |
|---------|---------|------|
| **产品实拍图** | `raw/cases/[编号]-[人名]/` | `raw/cases/786-马艳丽/786-real-1.jpg` |
| **AI 生成资产** | `raw/assets/generated/` | `raw/assets/generated/786-main-image-v6.png` |
| **Word 样图** | `raw/cases/[编号]-[人名]/` | `raw/cases/786-马艳丽/786-word-1.png` |
| **正式交付图** | `output/imagegen/[编号-产品名]/` | `output/imagegen/786-冰激凌水滴化妆包/主图/` |
| **通用附件** | `raw/assets/` | `raw/assets/tutorial/` |

### 4.2 命名规范

```
[产品编号]-[类型]-[描述]-[版本].扩展名
```

示例：
- `786-real-1.jpg` — 实拍图
- `786-main-image-v6.png` — 首图 v6
- `786-word-1.png` — Word 样图

---

## 5. 总结

| 场景 | Claude 怎么看到图片 |
|------|-------------------|
| 读笔记时 | 看到 `![[xxx.jpg]]` **文本**，不会自动渲染 |
| 需要看图时 | 用 Read 工具读取图片文件 → 多模态渲染 |
| 作图时 | 自动按 AGENTS.md 规则读取实拍图 |
| 你问问题时 | 直接说"读这张图"即可 |

> **关键原则：`![[xxx.jpg]]` 只是文本链接，图片文件需要单独用 Read 读取才能看到。**
