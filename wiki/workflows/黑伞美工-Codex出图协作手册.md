# 黑伞美工 Codex 出图协作手册
## 真实启动流程

你们现在的真实使用方式，第一步不是填卡，而是先报产品编号。

标准启动顺序：

1. 你先说要做哪个产品
   例如：`做 786`
2. Codex / Claude 先去飞书多维表格读取基础信息
   例如：产品编号、店铺、站点、ASIN、SKU、基础规格、历史案例、锁定母版
3. 你再提供开发文档和实拍图
   开发文档决定“这次做哪些图、每张图表达什么”；实拍图决定“产品真实长什么样”
4. Codex / Claude 再读取知识库、整理 brief、判断模型、生成 prompt

一句话：

> 先报产品编号，我先读飞书；再给开发文档和实拍图，我再写 prompt。

## 定位

Codex 是美工部门的辅助工具——**帮大家更快做对图**，不是来写文档的。

## Codex 做什么

1. **读需求** — 把零散信息整理成能出图的明确任务
2. **做图** — 结合参考图、产品资料，调用 AI 生成图片
3. **改图** — 根据反馈多轮收敛，不每次推翻重来
4. **少走弯路** — 调用知识库的历史经验、母版和规范

## 核心原则

AI 出图效果 80% 取决于输入质量。每次发指令前想清楚这四件事：

1. 你到底要什么图
2. 产品长什么样（给参考图）
3. 哪些东西不能改
4. 哪些地方可以发挥

## 3 秒速查卡

赶时间直接复制这段：

```text
帮我做一张 [主图 / A+ 图 / 场景图 / 信息图]。

产品：[编号 + 名称]
参考图：Image 1 是主体参考，Image 2 是细节参考，Image 3 是氛围参考

不能变：外形 / 数量 / 颜色 / 结构 / 配件
想优化：构图 / 氛围 / 版式 / 饱满度

先复述你的理解，再开始生成。
```

## 标准指令模板

所有出图需求统一用这个格式，不分场景：

```text
我要做的图：[主图 / A+ 图 / 场景图 / 细节图 / 尺寸图 / 广告图]

产品信息：
编号：
名称：
店铺：
站点：

参考图：
Image 1：
Image 2：
Image 3：

参考图角色：
Image 1 是产品主体参考，外形、颜色、结构必须严格一致。
Image 2 是材质 / 拉链 / 印花等细节参考。
Image 3 是构图 / 氛围参考，不是产品外形参考。

这张图的目标：
主要表达什么卖点？

绝对不能变：
- 产品外形、数量、颜色不能错
- 结构、配件不能改
- 不允许新增包装、手、logo、吊带等不存在元素

希望优化：
构图 / 氛围 / 光感 / 饱满度 / 信息层级

输出要求：
先复述你的理解，确认无误再生成。
```

## 出图前必查 5 问

发指令前快速过一遍：

- [ ] 说清楚这是什么图了吗？（主图 / A+ / 场景 / 信息）
- [ ] 给了参考图吗？
- [ ] 哪张是主体参考、哪张只是风格参考，说明白了吗？
- [ ] 写了"绝对不能变"的约束吗？
- [ ] 这轮到底改什么，写清楚了吗？

## 改图要点

- **不要重新来** — 基于当前图继续改，保留对的、只修错的
- **一次只改 1-3 个重点** — 改太多 AI 顾此失彼
- **按轮次收敛** — 第一轮看大方向，第二轮修结构，第三轮修精致度

可以直接说：

```text
不要重做，基于当前这张继续改。
保留：[哪些保留]
只修改：[哪些修改]
这轮目标：[具体目标]
```

## 最短工作口诀

> 先给参考图 → 先说不能变什么 → 再说想优化什么 → 一次只改几个重点 → 每轮更接近终稿
