# 黑伞美工 Codex 出图协作手册

## 定位

Codex 是黑伞美工部门的辅助工具。

它的核心职责不是单独维护知识库，而是帮助美工部门更快理解需求、更稳生成图片、更高效迭代修改，并通过知识库提高出图命中率、减少返工。

一句话理解：

> Codex 的价值不在“会聊天”，而在“帮你更快做对图”。

## Codex 在美工部门主要做什么

1. 帮我们读需求  
把运营、开发、老板给的零散信息整理成能出图的明确任务。

2. 帮我们做图  
结合参考图、产品资料、历史案例和规则，辅助生成更接近目标的图。

3. 帮我们改图  
根据反馈做多轮收敛，而不是每次推翻重来。

4. 帮我们少走弯路  
通过知识库调用历史经验、固定母版、失败案例和规范，提高出图成功率。

## 核心原则

AI 出图效果，80% 取决于输入质量。

以后所有协作都围绕四件事：

1. 你到底要什么图。
2. 产品长什么样。
3. 哪些东西不能改。
4. 哪些地方可以发挥。

## 出图前必须说清楚的事

### 1. 先给参考图，再谈生成

优先提供：

- 实拍图
- 白底图
- 已确认首图
- 历史成品图
- 竞品参考图
- 构图参考图

### 2. 先说“不变的东西”

例如：

- 产品外形不能变
- 材质不能变
- 图案不能变
- 颜色关系不能乱
- 数量不能错
- 配件不能丢

### 3. 再说“想优化的东西”

例如：

- 更高级
- 更饱满
- 更干净
- 更像亚马逊爆款
- 更适合美国市场
- 更适合做 A+

### 4. 一次不要改太多

一次只改 1 到 3 个重点。  
如果一口气改十几项，AI 很容易顾此失彼。

### 5. 不要让 AI 凭空想象产品

只要是产品图，尤其是主图、A+、场景图，必须尽量带参考图。  
产品一致性永远优先于场景花哨。

## 标准提需求格式

以后所有出图需求，尽量按这个格式发给 Codex：

```text
我要做的图：
这是主图 / A+ 图 / 场景图 / 尺寸图 / 细节图 / 广告图

产品信息：
产品编号 / 产品名 / 店铺 / 站点

必须参考的图片：
[实拍图路径]
[白底图路径]
[历史成品图路径]
[母版图路径]

这张图的目标：
我希望它传达什么卖点，解决什么问题

绝对不能变的地方：
产品外形 / 图案 / 数量 / 结构 / 配件 / 材质 / 色系

希望优化的地方：
构图 / 氛围 / 光感 / 饱满度 / 高级感 / 文案表达 / 信息层级

输出要求：
先给我你的理解，再生成
或者
先给我提示词草稿，再出图
```

## 五种最常见的出图场景

### 1. 做主图

目标：干净、明确、产品准。

```text
帮我做这款产品的主图。
必须严格参考我给的实拍图和白底图，不能改产品外形。
我要的是更适合电商点击的版本，但产品主体不能漂移。
先告诉我你理解的重点，再开始生成。
```

主图最重要的是：

- 产品要准
- 信息要清
- 排布要稳
- 一眼能卖

### 2. 做 A+ 图

目标：产品一致，卖点更完整。

```text
基于已经确认的主图母版，帮我做 A+ 图。
必须沿用同一产品主体，不允许整图重绘产品。
重点表达这些卖点：
[卖点列表]
场景和版式可以优化，但产品本身不能跑偏。
```

### 3. 做场景图

目标：有氛围，但产品还是对的。

```text
帮我做场景图。
产品必须和参考图保持一致，场景只是辅助，不是重画产品。
我想要的氛围是：
[节日感 / 温馨 / 美式家庭 / 高级 / 明亮 等]
重点让用户理解这个产品适合在什么场景使用。
```

### 4. 做细节图 / 信息图

目标：讲清楚，不要乱。

```text
帮我做细节信息图。
产品要用参考图中的真实形态，不要夸张改造。
重点表达：
[尺寸 / 材质 / 配件 / 结构 / 使用步骤]
整体信息要清楚，优先易读性，不要过度装饰。
```

### 5. 做“改图”而不是“重做”

```text
不要重做，基于当前这张继续改。
保留：
[哪些部分保留]
只修改：
[哪些部分修改]
修改目标是：
[更饱满 / 拉链修正 / 构图更稳 / 产品更立体]
其他地方尽量不动。
```

## 怎么让 Codex 更接近你想要的风格

不要只说“高级一点”“好看一点”，要拆开说。

例如把“高级感”拆成：

- 背景更干净
- 光线更柔和
- 配色更统一
- 排版更克制
- 留白更多
- 质感更真实

把“更适合亚马逊”拆成：

- 主体更突出
- 卖点更一眼看懂
- 文字更少
- 信息层级更清晰
- 不要花哨装饰
- 缩略图下也能看清重点

抽象词可以说，但一定要配具体说明。

## 多轮修改的正确方式

不要每次都推翻重来。  
正确做法是逐轮收敛。

第一轮：先看大方向

- 产品对不对
- 构图对不对
- 氛围对不对

第二轮：修结构错误

- 外形
- 比例
- 数量
- 拉链
- 配件
- 图案

第三轮：修卖点表达

- 信息清晰度
- 细节展示
- 场景匹配
- 文案层级

第四轮：修精致度

- 光影
- 质感
- 颜色
- 版式
- 氛围

可以直接这样要求：

```text
这一轮先不要追求终稿，只看三件事：
1. 产品外形是否正确
2. 构图是否成立
3. 卖点是否清楚

其他细节先不修。
```

## 什么时候必须先读知识库

知识库不是主角，但在这些时候必须先读：

1. 这个产品以前做过。
2. 这个店铺有固定风格。
3. 这个产品已有锁定母版。
4. 这个案例以前踩过坑。
5. 你不确定该用什么画法更稳。

这时可以直接说：

```text
先读这个产品相关的知识库页面，重点看以前的成品、失败点和锁定母版规则，再帮我出图。
```

知识库的作用是提高出图命中率，而不是为了单独写文档。

## 同事最容易犯的错误

1. 只说“做个图”，不给参考。
2. 给了参考图，但没说哪张是主体参考，哪张只是风格参考。
3. 想改很多东西，却不区分“必须不变”和“希望优化”。
4. 每轮都说“重新来”，导致结果越来越飘。
5. 明明产品已经有母版，还让 AI 整体重画。

## 最短工作口诀

- 先给参考图
- 先说什么不能变
- 再说想优化什么
- 一次只改几个重点
- 每轮都让结果更接近终稿
